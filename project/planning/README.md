# Planning

Esta carpeta organiza la ejecucion del producto sin crear una segunda verdad paralela.

## Regla principal

El documento canonico del producto es:

- `Docs/Docs_No_Eliminar/AgentWatch_Latam_requerimientos_v1_0_1_actualizado.md`

El PDF empresarial y arquitectonico se usa como marco complementario para:

- niveles estrategico, tactico y operativo;
- casos de uso del sistema;
- vision arquitectonica;
- trazabilidad entre operacion y reportes gerenciales.

## Archivos

- `master-plan.md`: mapa general de producto, features, entregables y secuencia.
- `features.md`: ficha formal de cada feature del MVP.
- `requirements-matrix.md`: RF, RNF, features, evidencia y estado.
- `use-cases-and-stories.md`: CU, HU y actores.
- `backlog.md`: backlog priorizado con items trazables.
- `backlog-items.md`: backlog item por backlog item con objetivo, DoD y evidencia.
- `traceability.md`: matriz fuente -> feature -> backlog -> sprint -> estado.
- `master-traceability-matrix.md`: tabla maestra unica para navegar RF/RNF/CU/HU -> feature -> backlog -> sprint.
- `sprints/`: definicion formal de cada sprint.

## Convencion de fuentes

Cada archivo de esta carpeta debe indicar:

- fuente principal en el `.md`;
- apoyo estructural del PDF;
- si existe alguna inferencia o consolidacion editorial.
